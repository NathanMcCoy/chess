# Chess

A chess site for chess.pacificfish.ca: play against Stockfish at different levels, review your games
move by move, and later play friends by challenge link or in open games.

## Plan

1. Play against Stockfish at different strengths: board with drawn arrows, move list, PGN download.
2. Game review: every move rated by how much it changed your chances.
3. Accounts (the password is a secret opening you play on the board), challenge links and open games.
4. A bot that starts out terrible and learns from the games it plays.

Stages 1 and 2 run entirely in the browser, Stockfish included, so the server only serves files.
